MeshX — Adaptive Off-Grid LoRa Mesh

ESP32-S3 + SX1262 nodes · BLE to Android · custom link-quality-aware routing. Tap everything.

How the whole project flows

Phone A → (BLE) → Node 1 → (LoRa hops, best-scoring path) → Node N → (BLE) → Phone B. No cellular, Wi-Fi or internet. The original contribution is the routing layer: it picks paths by measured link quality instead of hop count.

N8R8 uses GPIO35–37 for octal PSRAM — never wire to them. * GPIO3 is a strapping pin; if boot misbehaves use GPIO8/9. Any free GPIO works; match it in firmware.
Never transmit without the antenna attached — reflected power can destroy the SX1262 PA. Also match the antenna and module to one band (433/868/915 MHz) allowed in Pakistan; confirm with your supervisor first.
